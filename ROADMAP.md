# Project Roadmap

This document outlines the planned features and future direction for **SIMPEG Lapas**.

## Q1 2026: Foundation & Core Features (Current)
- [x] Admin Dashboard & Statistics.
- [x] Employee & Shift Management.
- [x] Geofencing & Selfie Attendance.
- [x] Leave Management.
- [x] Basic Inventory Tracking.
- [x] PDF Report Generation.

## Q2 2026: Enhancement & Integration
- [ ] **Mobile App (PWA):** Better mobile experience for field officers.
- [ ] **Biometric Authentication:** Face recognition integration for attendance.
- [ ] **Notification System:** WhatsApp/Telegram integration for shift reminders and leave approvals.
- [ ] **Advanced Analytics:** Deeper insights into employee performance and attendance trends.

## Q3 2026: Expansion & Security
- [ ] **API Access:** RESTful API for integration with other government systems.
- [ ] **Activity Audit Logs:** Detailed tracking of all administrative actions.
- [ ] **Multi-Lapas Support:** Ability to manage multiple prison facilities from a single instance.
- [ ] **Document Management:** Digital filing system for employee records (SK, certificates, etc.).

## Future Ideas
- [ ] AI-powered roster optimization.
- [ ] Integration with HRIS (Human Resource Information System) national portal.
- [ ] Offline-first support for attendance in areas with poor connectivity.

---
*Note: This roadmap is subject to change based on feedback and community needs.*
