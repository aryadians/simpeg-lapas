# Support Policy

Thank you for using SIMPEG Lapas. Here are the ways you can get support:

## Community Support
- **GitHub Issues:** For bug reports and feature requests, please use the [Issues](https://github.com/aryadians/simpeg-lapas/issues) section.
- **Discussions:** If you have questions about usage or need help with configuration, feel free to start a discussion in the [Discussions](https://github.com/aryadians/simpeg-lapas/discussions) tab (if enabled).

## Reporting Security Issues
Please **do not** report security vulnerabilities through public issues. Refer to our [Security Policy](SECURITY.md) for instructions on how to report security-related concerns.

## Professional Support
Currently, this is an open-source project. If you require professional support, custom feature development, or integration services, you can contact the maintainers at:
- **Email:** [maintainer@example.com] (Replace with actual email)
- **Website:** [https://example.com] (Replace with actual website)

## Version Support
We only provide support for the latest stable version of SIMPEG Lapas. Please ensure you are running the most recent version before seeking support.

## Information to Provide
When asking for help, please provide as much context as possible:
- Your OS and PHP version.
- Laravel version.
- Detailed steps to reproduce the issue.
- Relevant log entries from `storage/logs/laravel.log`.
